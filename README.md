
# OpsPilot AI

AI-Powered Production Monitoring & Incident Resolution Platform

## Project Overview

OpsPilot AI is a full-stack software engineering project designed to help engineering teams monitor application logs, detect incidents, and investigate potential root causes using AI.

## Planned Technology Stack

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- Data Engineering: Apache Kafka
- AI: LLM APIs, RAG, pgvector
- DevOps: Docker, AWS, GitHub Actions
